PHP Tips

  • Use `get_headers()` to Retrieve HTTP Headers
  • Use `header()` to Send HTTP Headers
  • Use `header_remove()` to Remove HTTP Headers
  • Use `setcookie()` to Set Cookies
  • Use `filter_input()` to Retrieve and Filter External Variables
  • Use `filter_var_array()` for Multiple Input Filtering
  • Use `parse_ini_string()` to Parse Configuration from a String
  • Use `parse_ini_file()` to Parse Configuration Files
  • Use `get_magic_quotes_gpc()` to Check Magic Quotes Status
  • Use `get_magic_quotes_runtime()` to Check Magic Quotes Runtime Status
  • Use `set_magic_quotes_runtime()` to Set Magic Quotes Runtime
  • Use `html_entity_decode()` to Convert HTML Entities Back to Characters
  • Use `get_html_translation_table()` to Retrieve HTML Translation Table
  • Use `chr()` to Convert ASCII Value to Character
  • Use `ord()` to Convert Character to ASCII Value
