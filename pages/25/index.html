PHP Tips

  • Use `stream_socket_accept()` to Accept a Connection
  • Use `stream_socket_enable_crypto()` to Enable Encryption on a Stream
  • Use `stream_socket_shutdown()` to Shutdown a Socket Connection
  • Use `stream_get_transports()` to List Available Socket Transports
  • Use `stream_set_blocking()` to Set Blocking Mode
  • Use `stream_set_timeout()` to Set Stream Timeout
  • Use `stream_socket_pair()` to Create a Pair of Connected Sockets
  • Use `proc_open()` to Execute a Command in a Subprocess
  • Use `proc_terminate()` to Terminate a Process
  • Use `proc_get_status()` to Retrieve Process Status
  • Use `proc_close()` to Close a Process Handle
  • Use `popen()` to Open a Pipe to a Process
  • Use `pclose()` to Close a Pipe
  • Use `system()` to Execute a Command and Output the Result
  • Use `exec()` to Execute a Command and Return the Output
