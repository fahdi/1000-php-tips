PHP Tips

  • Use `array_rand()` to randomly pick one or more keys from an array
  • Use `array_sum()` to calculate the sum of values in an array
  • Use `array_product()` to calculate the product of values in an array
  • Use `array_column()` to extract a single column from a multi-dimensional array
  • Use `array_merge_recursive()` to merge arrays recursively
  • Use `array_key_first()` to get the first key of an array
  • Use `array_key_last()` to get the last key of an array
  • Use `array_walk()` to apply a user-defined function to each element of an array
  • Use `array_reduce()` to reduce an array to a single value using a callback function
  • Use `array_map()` with `null` as the callback to remove elements from an array
  • Use `array_filter()` with `null` as the callback to remove empty elements from an array
  • Use `array_filter()` with `null` as the callback to remove empty elements from an array
  • Use `array_push()` to add one or more elements to the end of an array
  • Use `array_pop()` to remove and return the last element of an array
  • Use `array_shift()` to remove and return the first element of an array
