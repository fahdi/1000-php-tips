PHP Tips

  • Use `rewind()` to Rewind the File Pointer
  • Use `flock()` to Manage File Locks
  • Use `readfile()` to Output a File
  • Use `fpassthru()` to Output Remaining Data from a File Pointer
  • Use `file_exists()` to Check if a File or Directory Exists
  • Use `unlink()` to Delete a File
  • Use `copy()` to Copy a File
  • Use `rename()` to Rename a File or Directory
  • Use `mkdir()` to Create a Directory
  • Use `rmdir()` to Remove a Directory
  • Use `scandir()` to List Files in a Directory
  • Use `glob()` for Pattern Matching in File Names
  • Use `disk_free_space()` to Get Free Disk Space
  • Use `disk_total_space()` to Get Total Disk Space
  • Use `clearstatcache()` to Clear File Status Cache
