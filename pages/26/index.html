PHP Tips

  • Use `shell_exec()` to Execute a Command via Shell and Return the Output
  • Use `escapeshellarg()` to Escape a String for Shell
  • Use `escapeshellcmd()` to Escape a Command for Shell
  • Use `getenv()` to Retrieve Environment Variables
  • Use `putenv()` to Set Environment Variables
  • Use `getopt()` to Parse Command-Line Arguments
  • Use `date_parse()` to Parse a Date String
  • Use `date_parse_from_format()` to Parse a Date with a Specific Format
  • Use `date_diff()` to Calculate the Difference Between Dates
  • Use `date_add()` to Add an Interval to a Date
  • Use `date_sub()` to Subtract an Interval from a Date
  • Use `date_modify()` to Modify a Date
  • Use `date_time_set()` to Set the Time of a Date
  • Use `date_date_set()` to Set the Date
  • Use `date_isodate_set()` to Set the Date According to ISO 8601
