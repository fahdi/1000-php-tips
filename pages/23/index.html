PHP Tips

  • Use `password_verify()` to Verify Passwords
  • Use `password_needs_rehash()` to Check if a Hash Needs Rehashing
  • Use `mcrypt_encrypt()` for Encryption
  • Use `mcrypt_decrypt()` for Decryption
  • Use `openssl_encrypt()` for Encryption
  • Use `openssl_decrypt()` for Decryption
  • Use `openssl_sign()` for Digital Signatures
  • Use `openssl_verify()` to Verify Digital Signatures
  • Use `openssl_pkey_new()` to Generate a New Private Key
  • Use `openssl_pkey_export()` to Export a Private Key
  • Use `openssl_pkey_get_public()` to Get a Public Key
  • Use `openssl_seal()` to Encrypt Data with Multiple Public Keys
  • Use `openssl_open()` to Decrypt Sealed Data
  • Use `openssl_x509_parse()` to Parse a Certificate
  • Use `openssl_x509_checkpurpose()` to Check Certificate Purpose
