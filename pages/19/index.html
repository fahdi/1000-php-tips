PHP Tips

  • Use `is_readable()` to Check if a Path is Readable
  • Use `is_writable()` to Check if a Path is Writable
  • Use `is_executable()` to Check if a Path is Executable
  • Use `file_get_contents()` to Read a File into a String
  • Use `file_put_contents()` to Write a String to a File
  • Use `fopen()` to Open a File
  • Use `fclose()` to Close a File
  • Use `fread()` to Read from a File
  • Use `fwrite()` to Write to a File
  • Use `feof()` to Check for End-of-File
  • Use `fgets()` to Read a Line from a File
  • Use `fputs()` to Write a Line to a File
  • Use `fflush()` to Flush Output to a File
  • Use `fseek()` to Set the File Position
  • Use `ftell()` to Get the Current File Position
